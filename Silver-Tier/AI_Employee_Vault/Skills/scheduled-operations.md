# Scheduled Operations

Automate recurring tasks via Windows Task Scheduler or cron.

---

## When to Use

- Daily CEO Briefing (every morning at 8 AM)
- Hourly task processing (every hour)
- Weekly audit (every Sunday night)
- Monthly reports (first of each month)

## Skill 1: Windows Task Scheduler Setup

### Daily Briefing Task

**PowerShell Script to Create Task:**

```powershell
# Create-DailyBriefing.ps1
# Run this in PowerShell as Administrator

$taskName = "AI_Employee_Daily_Briefing"
$scriptPath = "E:\Personal-AI-Employee-Hackathon-0-FTEs\scripts\orchestrator.py"
$vaultPath = "E:\Personal-AI-Employee-Hackathon-0-FTEs\AI_Employee_Vault"
$pythonExe = "python"

# Create action
$action = New-ScheduledTaskAction -Execute $pythonExe `
  -Argument "-c `"import sys; sys.path.insert(0, 'scripts'); from orchestrator import Orchestrator; o = Orchestrator('$vaultPath'); o.run_cycle()`"" `
  -WorkingDirectory "E:\Personal-AI-Employee-Hackathon-0-FTEs"

# Create trigger (daily at 8 AM)
$trigger = New-ScheduledTaskTrigger -Daily -At 8:00AM

# Create settings
$settings = New-ScheduledTaskSettingsSet `
  -AllowStartIfOnBatteries `
  -DontStopIfGoingOnBatteries `
  -StartWhenAvailable `
  -RunOnlyIfNetworkAvailable

# Register task
Register-ScheduledTask `
  -TaskName $taskName `
  -Action $action `
  -Trigger $trigger `
  -Settings $settings `
  -Description "Generate daily AI Employee briefing at 8 AM" `
  -User "YourUsername"

Write-Host "Task '$taskName' created successfully"
```

### Hourly Processing Task

```powershell
# Create-HourlyProcessing.ps1

$taskName = "AI_Employee_Hourly_Processing"

$action = New-ScheduledTaskAction -Execute "python" `
  -Argument "scripts\orchestrator.py --vault AI_Employee_Vault --once" `
  -WorkingDirectory "E:\Personal-AI-Employee-Hackathon-0-FTEs"

# Trigger every hour
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) `
  -RepetitionInterval (New-TimeSpan -Hours 1) `
  -RepetitionDuration ([TimeSpan]::MaxValue)

Register-ScheduledTask `
  -TaskName $taskName `
  -Action $action `
  -Trigger $trigger `
  -Description "Process tasks every hour"
```

### Weekly Audit Task

```powershell
# Create-WeeklyAudit.ps1

$taskName = "AI_Employee_Weekly_Audit"

$action = New-ScheduledTaskAction -Execute "python" `
  -Argument "scripts\orchestrator.py --vault AI_Employee_Vault --generate-briefing" `
  -WorkingDirectory "E:\Personal-AI-Employee-Hackathon-0-FTEs"

# Trigger every Sunday at 9 PM
$trigger = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Sunday -At 9:00PM

Register-ScheduledTask `
  -TaskName $taskName `
  -Action $action `
  -Trigger $trigger `
  -Description "Generate weekly CEO briefing every Sunday"
```

## Skill 2: View and Manage Tasks

### List All AI Employee Tasks

```powershell
Get-ScheduledTask -TaskName "AI_Employee_*" | 
  Select-Object TaskName, State, LastRunTime, NextRunTime
```

### Check Task History

```powershell
Get-ScheduledTaskInfo -TaskName "AI_Employee_Daily_Briefing" | 
  Format-List *
```

### Run Task Manually (for testing)

```powershell
Start-ScheduledTask -TaskName "AI_Employee_Daily_Briefing"

# Wait and check status
Start-Sleep -Seconds 30
Get-ScheduledTaskInfo -TaskName "AI_Employee_Daily_Briefing"
```

### Delete Task

```powershell
Unregister-ScheduledTask -TaskName "AI_Employee_Daily_Briefing" -Confirm:$false
```

## Skill 3: Daily Briefing Generation

### Briefing Template

```markdown
---
generated: 2026-02-28T08:00:00
period: 2026-02-27
type: daily_briefing
---

# Daily Briefing - 2026-02-27

## Executive Summary
[Brief 2-3 sentence summary of the day]

## Tasks Completed
| Task | Type | Time | Status |
|------|------|------|--------|
| [task 1] | [type] | [time] | ✅ |
| [task 2] | [type] | [time] | ✅ |

**Total:** X tasks completed

## Pending Approvals
| Request | Type | Created | Status |
|---------|------|---------|--------|
| [approval 1] | [type] | [time] | ⏳ |

**Total:** X pending approvals

## Key Metrics
| Metric | Today | Week Avg | Status |
|--------|-------|----------|--------|
| Tasks Completed | X | X.X | 🟢/🟡/🔴 |
| Response Time | Xh | Xh | 🟢/🟡/🔴 |
| Approval Rate | X% | X% | 🟢/🟡/🔴 |

## Notes & Observations
[Any notable patterns or issues]

## Suggestions for Improvement
- [Suggestion 1]
- [Suggestion 2]

---
*Generated by AI Employee v0.2.0 (Silver Tier)*
```

### Generation Process

```
1. Read /Done/*.md for completed tasks (today)
2. Read /Pending_Approval/*.md for pending items
3. Read /Logs/YYYY-MM-DD.jsonl for activity
4. Calculate metrics:
   - Task count
   - Average completion time
   - Approval rate
5. Generate briefing file
6. Write to /Briefings/YYYY-MM-DD_Briefing.md
7. Update Dashboard.md with summary
```

## Troubleshooting

### Task Not Running

```powershell
# Check task status
Get-ScheduledTaskInfo -TaskName "AI_Employee_Daily_Briefing"

# Check last result
(Get-ScheduledTaskInfo -TaskName "AI_Employee_Daily_Briefing").LastTaskResult

# 0 = Success, non-zero = Error
```

### Task Runs But Fails

```powershell
# View task history
Get-WinEvent -FilterHashtable @{
  LogName='Microsoft-Windows-TaskScheduler/Operational'
  Id=100,102,201
} | Where-Object {$_.Message -like "*AI_Employee*"} | Select-Object -First 10
```

### Fix Permission Issues

```powershell
# Run as different user
Register-ScheduledTask `
  -TaskName "AI_Employee_Daily_Briefing" `
  -User "DOMAIN\Username" `
  -Password (ConvertTo-SecureString "password" -AsPlainText -Force)
```
