INSTAGRAM TROUBLESHOOTING SUMMARY
═══════════════════════════════════════════════════════════════════

Issue Encountered:
  Error: "Only photo or video can be accepted as media type" (code: 9004)
  Subcode: 2207052
  Message: "Media download has failed"

Root Cause:
  Instagram's servers couldn't download images from certain CDNs:
  ✗ picsum.photos - Blocked/rate-limited by Instagram
  ✗ fastly.picsum.photos - Same issue (redirect URLs)
  ✗ i.imgur.com - Wrong aspect ratio
  ✓ Wikipedia CDN - Works perfectly

Solution:
  Use image URLs from Instagram-compatible hosts:
  ✓ Wikipedia Commons
  ✓ Your own server/CDN
  ✓ Major cloud providers (AWS S3, Google Cloud Storage, etc.)
  ✓ Direct image URLs (no redirects)

Requirements for Instagram Images:
  1. Direct URL to image file (.jpg, .png)
  2. Publicly accessible (no authentication)
  3. Proper aspect ratio (1:1, 4:5, 16:9)
  4. From a CDN Instagram can access
  5. No redirects (direct image response)
